### Terraform — 6ヶ月

GCP 移行プロジェクトで、Azure 環境の構成をコード化する形で使用しました。
モジュール化による再利用性を意識した構成を作っています。

現時点では**ドキュメントを参照しながら実装するレベル**です。
継続的に触れている状態ではないため、
このポートフォリオサイトの構築を通じて実践量を増やしているところです。

### PowerShell

Active Directory のユーザー・端末情報を一括取得・エクスポートする
自動化スクリプトを開発。手作業の工数削減とヒューマンエラーの排除を実現しました。

### 生成AI の実務活用

Gemini の Gem 機能でインフラ構築サポートエージェントを自作し、チームへ展開。
Terraform のコードと設計仕様をナレッジとして登録することで、
設計方針とコーディング規約の標準化を実現しました。

日常的に Claude Code / Gemini を業務へ組み込み、
技術調査の効率化やドキュメント整備に活用しています。
