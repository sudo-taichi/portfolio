## 概要

1,000名規模のエンタープライズ環境における、Microsoft Entra ID の
追加要件定義および構築による機能拡張・運用最適化を担当。
グローバル拠点を含む多国籍環境を対象とした、デバイス制御ポリシーの
設計・構築・展開までを一貫して実施した。

## 課題

海外拠点において、個人所有端末の業務利用が管理外で行われている状態にあった。
BYOD と社給端末が混在し、かつ国ごとに事情が異なるため、
一律のポリシーを適用すればシャドーIT は防げても業務が回らなくなる。

また複数のポリシーを同時適用した際の評価順序や相互依存関係が複雑で、
設計を誤れば本番環境でログイン障害を引き起こすリスクを抱えていた。

## 取り組み

### プラットフォーム別のポリシー設計

Windows / macOS / iOS / Android それぞれの特性に応じた
条件付きアクセスポリシーを個別に設計・構築した。

社用モバイル端末のアプリ制御については、MAM（モバイルアプリケーション管理）
ポリシーと条件付きアクセスを組み合わせた制御ロジックを設計。
セキュリティ水準を維持しながら、必要なアプリ利用は妨げない構成とした。

### 国ごとの事情を踏まえた柔軟な設計

BYOD と社給端末の混在状況は拠点ごとに異なるため、
一律適用ではなく国別の実態に合わせたポリシー設計を実施。

展開スケジュールについても各拠点の時差を考慮して策定し、
現地の業務時間中に切り替えが発生しないよう調整した。

### 網羅的なテストによる事前検証

複数ポリシー適用時の評価順序と相互依存関係の仕様を分析し、
本番環境を想定したテスト計画を立案・実行。
想定される組み合わせを網羅的に検証してから展開に移した。

### ネットワーク製品との連携課題の解消

ネットワークプロキシ製品との連携時に発生した認証エラーについて、
ログと仕様に基づく原因解析を実施し、解決策を策定・適用した。

## 成果

- 技術的制御により、個人端末からの業務環境アクセスをブロックする仕組みを構築。
  グローバル環境全体のセキュリティガバナンスを強化
- 事前の網羅的テストにより、**本番展開時のログイン障害を発生させることなく**
  全拠点への適用を完遂
- 各国の要件に最適化されたセキュリティ基準を適用し、
  業務影響を最小限に抑えた展開を実現

## 技術構成

| 領域 | 採用技術 |
|---|---|
| ID 管理 | Microsoft Entra ID（条件付きアクセス / ネームドロケーション） |
| デバイス管理 | Microsoft Intune（MDM / MAM ポリシー） |
| 対象プラットフォーム | Windows / macOS / iOS / Android |
| ネットワーク | SASE / SWG 製品との連携 |
| エンドポイント保護 | EDR 製品との連携 |
