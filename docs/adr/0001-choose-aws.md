# ADR 0001: ポートフォリオ基盤に AWS を採用する

## ステータス

承認済み（2026-08）

## 背景

ポートフォリオサイトの配信基盤として、Azure / AWS / GCP のいずれかを選ぶ必要があった。

自身の実務経験は Azure が最も長く（約1年、AZ-305 Expert 保有）、AWS は3ヶ月（AWS-SAA 保有）、
GCP は2ヶ月という状況にある。

## 検討した選択肢

**Azure** — 実務経験が最も豊富で、設計判断に迷いが少ない。Static Web Apps を使えば
無料枠での運用も可能。

**AWS** — 実務経験は薄いが、S3 + CloudFront + OAC は静的サイト配信の定番構成であり、
参考資料が豊富。CloudFront 定額料金プランにより無料での運用が可能。

**GCP** — 経験が最も浅く、学習コストが高い。

## 決定

**AWS を採用する。**

## 理由

職務経歴書上、AWS の実務経験は3ヶ月と最も薄い。この基盤を自力で設計・構築することで、
資格保有と実務経験のギャップを実物で埋められる。

Azure の設計力は既に業務実績として証明済みであり、同じ領域を重ねるより、
薄い部分を補完する方が全体の説得力が増すと判断した。

また S3 + CloudFront + OAC + OIDC は「well-architected な静的サイト」の
模範解答的な構成であり、レビュアーに設計意図が伝わりやすい。

## 結果

- AWS 上に本番稼働する環境を構築し、Terraform で全リソースをコード管理
- CloudFront 定額料金プラン Free ティアにより月額 $0 で運用
- 実務では未経験だった OIDC 連携、OAC、WAF v2 を実際に設定
